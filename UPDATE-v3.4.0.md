# Bibo v3.4.0 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v3.4.0-update.zip
cd Bibo-v3.4.0
sudo bash install.sh
```

Neu: Boxsets und Sammelausgaben besitzen eine explizite Abdeckung für mehrere Filme, Staffeln oder Bände. Der Reihenfortschritt berücksichtigt diese Inhalte, während der physische Boxpreis nur einmal in den Gesamtwert eingeht.
