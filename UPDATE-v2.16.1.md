# Update auf GameCollector v2.16.1

Dieses Hotfix korrigiert die Zielpfade der Konsolenreihen. Jede Karte öffnet nun ihre eigene Detailseite.

## Installation aus dem Downloads-Ordner

```bash
sudo su
mkdir -p /opt/gamecollector/updates/v2.16.1
cd /opt/gamecollector/updates/v2.16.1
unzip $HOME/Downloads/GameCollector-v2.16.1-update.zip
cd GameCollector-v2.16.1
chmod +x install.sh
./install.sh
```
