# Bibo v4.4.1 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.4.1-update.zip
cd Bibo-v4.4.1
sudo bash install.sh
```

Hotfix für TV-Komplettboxen: Markiere in der Serienansicht alle enthaltenen Staffeln, wähle oben die physische Box und klicke auf **Box zuordnen**. Bibo speichert ein Exemplar mit einem Gesamtpreis, kennzeichnet aber jede enthaltene Staffel als vorhanden.
