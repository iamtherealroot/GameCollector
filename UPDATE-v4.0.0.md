# Bibo v4.0.0 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.0.0-update.zip
cd Bibo-v4.0.0
sudo bash install.sh
```

Das Update ist kumulativ und enthält alle Änderungen von 3.2.0 bis 4.0.0. Vor der Aktualisierung legt das Installationsskript automatisch ein Backup an und prüft nach dem Start Version, Datenbank und Schema.

Neu in 4.0: Die gemeinsame Bibliothek verbindet Werke, Reihen, Ausgaben und Exemplare aus Spielen, Filmen, Serien, Büchern, Musik, Karten, Hardware und Zubehör. Das Register ergänzt die vorhandenen Datenbanken nicht-destruktiv; bestehende Datensätze und IDs bleiben erhalten.
