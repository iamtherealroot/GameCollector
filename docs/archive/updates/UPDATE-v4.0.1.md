# Bibo v4.0.1 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.0.1-update.zip
cd Bibo-v4.0.1
sudo bash install.sh
```

Neu: Die großen Bereichskacheln der Startseite verwenden echte Cover aus der eigenen Sammlung. Ein dunkler Verlauf hält Titel, Bestandszahlen und Werte gut lesbar. Das Paket ist kumulativ und enthält sämtliche Funktionen von Bibo 4.0.0.
