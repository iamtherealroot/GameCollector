# Update auf Bibo v3.0.6

1. ZIP nach `/opt/gamecollector/updates/` kopieren und entpacken.
2. In das entpackte Verzeichnis wechseln.
3. Update mit `sudo bash install.sh` starten.

Der Installer erstellt zuerst ein Programm- und Datenbankbackup. Beim ersten Start entfernt Bibo ausschließlich fehlerhafte eBay-Bewertungsartefakte von erkannten Pokémon-Karten. Manuelle Fixierungen und PokéCollector-Werte bleiben erhalten.

Nach dem Update einmal „PokéCollector synchronisieren“ ausführen, falls eine Karte zuvor noch einen eBay-Hauptwert hatte.
