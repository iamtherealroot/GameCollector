# Update auf Bibo v3.0.7

1. ZIP nach `/opt/gamecollector/updates/` kopieren und entpacken.
2. In das entpackte Verzeichnis wechseln.
3. Update mit `sudo bash install.sh` starten.

Bei Büchern gibt es danach keine medienbezogene Vollständigkeitsauswahl mehr. Vorhandene Buchdaten, Preise, Reihen und Notizen bleiben erhalten.
