# Bibo v4.5.2 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.5.2-update.zip
cd Bibo-v4.5.2
sudo bash install.sh
```

Das Update ist kumulativ; v4.5.0 und v4.5.1 müssen vorher nicht installiert werden.

Neu sind kurze Bestandsaufteilungen in allen Dashboard-Kacheln, schnelle Aktionsfelder zur Staffelauswahl bei Komplettboxen und eine automatische Reparatur älterer Gesamtboxen. Eine Komplettbox wird allen enthaltenen Staffeln zugeordnet, bleibt beim Gesamtwert aber weiterhin genau ein Exemplar.
