# Bibo v4.5.3 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.5.3-update.zip
cd Bibo-v4.5.3
sudo bash install.sh
```

Das Update ist kumulativ; frühere v4.5-Pakete müssen vorher nicht installiert werden.

Der Medienassistent zeigt Cover-Links jetzt als sofortige Bildvorschau und erneut in der Abschlusskontrolle. Zusätzlich unterscheidet Bibo vollständige Staffelboxen von echten Serien-Komplettboxen und bereinigt frühere automatische Fehlzuordnungen, ohne manuelle Verknüpfungen zu verändern.
