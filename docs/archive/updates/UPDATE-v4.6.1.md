# Bibo v4.6.1 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.6.1-update.zip
cd Bibo-v4.6.1
sudo bash install.sh
```

Das Update ist kumulativ. v4.6.0 oder ältere v4-Pakete müssen vorher nicht installiert werden.

Werkdetailseiten zeigen ähnliche Titel jetzt als kleine Cover-Vorschau mit den Kennzeichnungen „Im Besitz“, „Auf der Wunschliste“ oder „Nicht in der Sammlung“. Beim Box-/Ausgabeninhalt von Filmen können außerdem mehrere TMDB-Film-Links beziehungsweise IDs direkt übernommen werden. Der Boxpreis bleibt ein einzelner Wert und ein physischer Deutschland-Status wird daraus nicht automatisch abgeleitet.
