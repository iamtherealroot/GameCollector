# Bibo v4.4.0 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.4.0-update.zip
cd Bibo-v4.4.0
sudo bash install.sh
```

V4.4 ist kumulativ und enthält alle Neuerungen von V4.1 bis V4.4: die individuelle zeitabhängige Begrüßung, zentrale Erfassung und Suche, Planungszentrale, Lagerorte mit QR-Inventur, Leihverwaltung, fein einstellbare Sammlungsrechte, CSV-Änderungsnachweis und administrative Systemdiagnose.
