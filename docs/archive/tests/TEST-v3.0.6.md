# Prüfliste Bibo v3.0.6

- Eine ältere Karte mit `tcg_game = Pokémon TCG` darf weder einzeln noch im Sammellauf über eBay bewertet werden.
- Bei einer PokéCollector-Karte sind Bewertungsaktionen durch den PokéCollector-Hinweis ersetzt.
- PokéCollector-Synchronisierung setzt den Einzelwert und entfernt alte Min-/Max-Spannen.
- Historische eBay-Aktivitäten und eBay-Preisverläufe erkannter Pokémon-Karten werden beim Start bereinigt.
- Pokémon-Karten erscheinen nicht in Gewinnern/Verlierern und nicht in der allgemeinen Preisaktivität.
- Manuelle Preisfixierungen und gültige PokéCollector-Werte bleiben erhalten.
