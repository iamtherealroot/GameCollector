# GameCollector v2.14.5

- Pokémon-Werte sind exklusiv PokéCollector: täglicher Collector-Bewertungsjob überspringt Pokémon hart.
- Manuelle Collector-Sammelbewertung löst keinen PokéCollector-Sync mehr aus.
- PokéCollector-Sync bevorzugt den vom Sammlungsdatensatz gelieferten Wert; ein vom API gelieferter Portfolio-Gesamtwert wird 1:1 im Dashboard verwendet.
- Filmreihen zeigen mehrere physische Ausführungen desselben Films einzeln unter dem Film (analog Mehrfachexemplaren bei Spielen/FIFA), zählen den Film aber nur einmal für den Reihenfortschritt.
