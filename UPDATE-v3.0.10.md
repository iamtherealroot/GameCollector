# Update auf Bibo v3.0.10

Dieses kleine Oberflächenupdate ergänzt die Cover in der Games-Listenansicht. Alle Funktionen aus v3.0.9 sind enthalten.

## Installation

```bash
cd $HOME/Downloads
unzip -o Bibo-v3.0.10-update.zip
cd Bibo-v3.0.10
sudo bash install.sh
```

Vor der Aktualisierung erstellt das Installationsskript automatisch ein Backup.
