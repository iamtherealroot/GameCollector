# Bibo v4.6.0 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.6.0-update.zip
cd Bibo-v4.6.0
sudo bash install.sh
```

Das Update ist kumulativ. Frühere v4.x-Pakete müssen vorher nicht installiert werden.

Neu sind bebilderte, anklickbare Empfehlungen für Games, Filme, Serien, Bücher, Musik und Sammelkarten. Titel lassen sich in einer internen Vorschau prüfen, ausblenden, vormerken oder vorausgefüllt über den Fragenkatalog anlegen. Bereits vorhandene Titel werden herausgefiltert und ein physischer Deutschland-Status wird ohne Bestätigung niemals angenommen.

Der Fragenkatalog verwendet für „Medium / Format“ jetzt eine zur Medienart und Besitzform passende Auswahlliste. Alle Korrekturen aus v4.5.3 – einschließlich Coverprüfung, Serien-Komplettboxen und Dashboard-Aufteilungen – sind enthalten.
