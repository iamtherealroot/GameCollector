# Bibo v4.5.0 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.5.0-update.zip
cd Bibo-v4.5.0
sudo bash install.sh
```

Neu ist der geführte Medienassistent unter **Zentral hinzufügen → Fragenkatalog starten**. Er fragt in sechs Schritten nur passende Angaben für Filme, Serien, Bücher, Musik, Sammelkarten und eigene Objekte ab. Serien-Komplettboxen können direkt mit Angaben wie `1-6` allen enthaltenen Staffeln zugeordnet werden; ihr Preis bleibt ein einmaliger Boxpreis.
