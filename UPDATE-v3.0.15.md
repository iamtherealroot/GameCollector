# Bibo v3.0.15 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v3.0.15-update.zip
cd Bibo-v3.0.15
sudo bash install.sh
```

Neu: Reihenfortschritt zählt logische Einheiten statt Datenträger. Geteilte Staffeln wie 8.1/8.2 zählen einmal; doppelte Film-Editionen und Buchausgaben erhöhen den Reihenfortschritt ebenfalls nicht. Physische Exemplare und ihr Gesamtwert bleiben separat erhalten.
