# Update auf GameCollector v2.16.2

Dieses Hotfix verbindet ältere Bourne-Einträge zuverlässig mit der vollständigen Filmreihe und vereinheitlicht die Schreibweisen Fußball/Fussball/FIFA Manager.

## Installation aus dem Downloads-Ordner

```bash
sudo su
cd /
mkdir -p /opt/gamecollector/updates/v2.16.2
unzip $HOME/Downloads/GameCollector-v2.16.2-update.zip -d /opt/gamecollector/updates/v2.16.2
cd /opt/gamecollector/updates/v2.16.2/GameCollector-v2.16.2
chmod +x install.sh
./install.sh
```
