# Bibo v4.3.0 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.3.0-update.zip
cd Bibo-v4.3.0
sudo bash install.sh
```

Neu: hierarchische Lagerorte mit eigenem QR-Code, mobile Inventur je Lagerort und eine Leihverwaltung mit Entleiher, Fälligkeit, Rückgabe und Überfällig-Markierung. Alle Funktionen arbeiten auf dem gemeinsamen Bibo-Register und bleiben pro Sammlung getrennt.
