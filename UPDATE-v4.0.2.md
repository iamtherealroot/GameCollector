# Bibo v4.0.2 installieren

```bash
cd $HOME/Downloads
unzip -o Bibo-v4.0.2-update.zip
cd Bibo-v4.0.2
sudo bash install.sh
```

Neu: Jede große Startseiten-Kachel zeigt bis zu fünf echte Cover aus dem jeweiligen Sammlungsbereich. Die Cover wechseln alle sechs Sekunden mit weicher Überblendung; die Kacheln starten leicht zeitversetzt. Bei nur einem Cover bleibt das Bild stehen, und die Betriebssystem-Einstellung zur Bewegungsreduzierung wird respektiert.
